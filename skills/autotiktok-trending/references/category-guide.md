# TikTok 题材分类与 AI 复刻适配性指南

## 适合 AI 复刻的题材

### 1. 运动图形 / Motion Graphics（基线分: 95）

- **官方 hashtag**: #motiondesign #animation #motiongraphics #3d #aftereffects
- **典型结构**: 纯数字内容，循环动画 + 配乐，15-30 秒
- **为什么适合**: 完全由 AI 生成，无真人依赖，Runway/Pika/Kling 均可直接生成
- **推荐工具**: Runway Gen-3, Pika, Kling AI

### 2. 图片轮播 / Slideshow（基线分: 90）

- **官方 hashtag**: #slideshow #photoslideshow #compilation #top10 #listformat
- **典型结构**: 图片 + 文字叠加 + 背景音乐，每张 2-3 秒，总 15-60 秒
- **为什么适合**: 图文+音乐组合，AI 生成图片后编排即可
- **推荐工具**: Canva AI, Midjourney + CapCut

### 3. 治愈/ASMR / Satisfying（基线分: 85）

- **官方 hashtag**: #satisfying #asmr #oddlysatisfying #slime #cleaning
- **典型结构**: 物品特写，重复动作，配合音效，15-60 秒
- **为什么适合**: 以物体为中心，无需面部，动作模式固定
- **推荐工具**: Kling AI, Runway Gen-3

### 4. 教育类 / Educational（基线分: 80）

- **官方 hashtag**: #learnontiktok #edutok #didyouknow #facts #science
- **典型结构**: 图表/文字动画 + 旁白解说，30-60 秒
- **为什么适合**: 以信息图形和旁白为主，TTS 可替代真人语音
- **推荐工具**: D-ID (数字人), ElevenLabs (TTS) + Motion graphics

### 5. 烹饪/食谱 / Cooking（基线分: 80）

- **官方 hashtag**: #recipe #cooking #foodtiktok #easyrecipe #homecooking #baking
- **典型结构**: 俯拍视角，手部操作 + 食材特写 + 步骤字幕，30-90 秒
- **为什么适合**: 固定机位，以食材为主体，手部动作可 AI 生成
- **推荐工具**: Kling AI (物体动画), Runway Gen-3

### 6. 教程/How-To / Tutorial（基线分: 75）

- **官方 hashtag**: #tutorial #howto #diy #lifehack #tips #hack
- **典型结构**: 屏幕录制或手部操作 + 步骤字幕 + 旁白，30-90 秒
- **为什么适合**: 结构化内容，可通过屏幕录制+AI旁白复刻
- **推荐工具**: Screen recording + ElevenLabs TTS

### 7. 产品测评 / Product Review（基线分: 70）

- **官方 hashtag**: #review #unboxing #haul #amazonfinds #tiktokmademebuyit
- **典型结构**: 产品特写 + 开箱 + 文字评分，30-60 秒
- **为什么适合**: 以产品为中心，可用产品图片+AI旁白替代
- **推荐工具**: Midjourney (产品图) + ElevenLabs + CapCut

### 8. 风景/旅行 / Scenery（基线分: 70）

- **官方 hashtag**: #scenery #travel #nature #landscape #sunset #drone
- **典型结构**: 航拍/延时摄影 + 配乐，15-60 秒
- **为什么适合**: 纯景观画面，AI 视频生成模型擅长此类
- **推荐工具**: Runway Gen-3, Sora, Kling AI

### 9. 宠物 / Pet（基线分: 60）

- **官方 hashtag**: #pet #dogsoftiktok #catsoftiktok #cute #animals #puppy
- **典型结构**: 宠物日常 + 配乐/配文，15-30 秒
- **为什么适合**: 动物动作可生成，但自然度仍有挑战
- **推荐工具**: Kling AI, Runway Gen-3 (动物动画质量在提升)

## 不适合 AI 复刻的题材

### 个人 Vlog（排除）

- **hashtag 信号**: #vlog #dayinmylife #grwm #getreadywithme
- **原因**: 强烈依赖真人面部和个人身份，AI 换脸有伦理问题

### 舞蹈/编舞（排除）

- **hashtag 信号**: #dance #choreography #dancechallenge
- **原因**: 复杂人体运动，当前 AI 生成的人体动作不自然

### 直播/新闻（排除）

- **hashtag 信号**: #live #news #breaking
- **原因**: 需要实时信息准确性，AI 不应生成新闻内容

### 合拍/缝合反应（排除）

- **hashtag 信号**: #duet #stitch #reaction
- **原因**: 依赖原创者内容，存在版权和身份问题

### 访谈/播客片段（排除）

- **hashtag 信号**: #interview #podcast #conversation
- **原因**: 真人对话，无法有意义地复刻

### UGC 挑战（排除）

- **hashtag 信号**: #challenge #trend
- **原因**: 需要特定人参与，AI 生成缺乏真实感

## 时长适配性

| 时长范围             | 评分调整 | 说明                          |
| -------------------- | -------- | ----------------------------- |
| 15-60 秒             | +10      | AI 视频生成最佳时长           |
| 10-15 秒 或 60-90 秒 | +5       | 可接受范围                    |
| < 5 秒               | -15      | 太短，缺乏内容                |
| > 180 秒             | -10      | 太长，AI 生成成本高且质量下降 |
